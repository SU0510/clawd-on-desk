- Claude Code identified three core bugs causing dock-walk detection failure on Windows: (1) **Call order bug** — `handleDetectClick` calls `cancelDetection("success")` first, which calls `restoreHitWinSize()` (showing hitWin at pet size), before `hideHitWin()` runs, so hitWin is still visible and on-top during `WindowFromPoint`; (2) **DPI scaling bug** — `hit-renderer.js` calculates screen coordinates in DIP (logical pixels) via `window.screenX + clientX`, but `WindowFromPoint` expects physical pixels — at 150% scaling, coordinates are off by 1.5x; (3) **Render window occlusion** — `win` (the render window) is also `alwaysOnTop: true`, so even hiding hitWin leaves win blocking `WindowFromPoint` at the pet's position.

- Claude Code verified that the render window `win` is created with `alwaysOnTop: true` in `src/pet-window-runtime.js` line 414, and that `getOwnWindowIds` in `src/main.js` lines 1456-1469 collects both windows' HWNDs but the filter in `winGetWindowAtPoint` returns `null` instead of trying the next window when it hits an own window.

- Claude Code confirmed no DPI/scaleFactor handling exists anywhere in `src/dock-walk-detect.js` or the coordinate path, and that `screen.getPrimaryDisplay().scaleFactor` is available but unused.

- Claude Code found the default theme setting at `src/prefs.js` line 88: `theme: { type: "string", default: "clawd" }`, and confirmed the pomeranian theme exists at `themes/pomeranian/` with `dockWalk.supported: true` in its theme.json.

- Claude Code proposed a comprehensive 5-part fix: (1) rewrite `handleDetectClick` in `src/dock-walk.js` to manually cancel detection without restoring hitWin, and use `hideOwnWindows`/`showOwnWindows` to hide both windows; (2) replace `hideHitWin`/`showHitWin` in `src/main.js` with `hideOwnWindows`/`showOwnWindows` that hides both hitWin and win; (3) add DPI scaling in `src/dock-walk-detect.js` by multiplying DIP coordinates by `scaleFactor` before passing to `WindowFromPoint`; (4) pass `screen.getPrimaryDisplay().scaleFactor` in the `detectWindowAtPoint` wrapper in `src/main.js`; (5) change default theme in `src/prefs.js` from `"clawd"` to `"pomeranian"`.
